# Fiche molécule

Application web (HTML / CSS / JavaScript) : on tape une molécule, elle affiche
sa structure, son CAS, sa formule brute, sa masse molaire et son point d'ébullition.
Les données viennent de l'API publique de PubChem.

## Lancer en local
Ouvrir `index.html` dans le navigateur (ou utiliser l'extension « Live Server » de VS Code).

## Déploiement
Dépôt Git -> GitHub -> import dans Vercel (voir les étapes dans la conversation).
